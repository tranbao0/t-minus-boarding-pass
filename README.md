# T-Minus Boarding Pass

Clock-safe countdown lock screens and calendar reminders styled as a Swiss boarding pass for trips and study abroad departures.

## Features

- Live Phone (9:19.5) and Laptop (16:9) lock screen previews with toggleable OS clock overlays and safe-zone guides.
- One-click export of crisp native-resolution PNG wallpapers (1290x2796 for phone, 3840x2160 4K for laptop) without OS overlays.
- Interactive T-minus milestone checklist synced to the boarding pass, plus three trip presets and three backgrounds (Matte Slate, Aviation Cobalt, Cool Frost).
- RFC-5545 `.ics` calendar export with milestone alerts and an optional daily countdown check-in for Google Calendar and Apple Calendar.
- URL-hash sharing so friends on a group trip open the same boarding pass and checklist.
- Built-in Gemini planning, design, and reminder prompts synced to your active route and departure date.

## Usage

Open `index.html` in any modern browser or serve the folder statically.
No build step or external runtime is required.
